# V29 design — reproduce the upstream public 0.55 model regime

Frozen on **2026-09-13 before GPU feasibility**.

## Why this experiment exists

The refreshed audit downloaded all 66 currently available public competition kernels. Most high notebook-title scores predate the August PQ reset, and current transparent methods cluster at genuine PQ <=0.39. Two apparent public 0.55 methods are not independent:

- HDJoJo's public notebook runs a private `magfilo_260825_yolov8l_seg_imgsz2048_nc1.pt` checkpoint with YOLOv8l segmentation at `imgsz=2048`, `conf=0.3`, `iou=0.0` and writes 1,342 masks;
- Lâm Huy's claimed U-Net submission decodes an embedded `CHAMPION_PAYLOAD` and never runs the demonstrated U-Net on test images;
- HDJoJo's generated CSV and Lâm Huy's decoded payload are byte-identical: 388,929 bytes, SHA-256 `7e6570382c620ce402bb0048336a319cd1a590bb08facb66bec3729c622de7e4`.

Thus the only actionable upstream public 0.55 evidence is one native-resolution, large YOLO segmentation model—not a U-Net and not two independent recipes.

## What the local project has not tested

V18 is not this experiment. V18 used the smaller YOLO11s architecture, warm-started from V6, at `imgsz=1536` and `mask_ratio=1`. It OOMed because full-resolution mask loss scales with instance count. Ultralytics' normal segmentation default is `mask_ratio=4`, reducing mask-loss area by 16x relative to `mask_ratio=1`. A larger backbone with the coarser default mask target can therefore fit even though V18 did not.

No local run trained official COCO-pretrained YOLOv8l-seg at 2048 with default mask ratio 4.

## Frozen feasibility configuration

- model: official `yolov8l-seg.pt` COCO-pretrained checkpoint;
- input: native `2048 × 2048`;
- batch: 1 on one T4;
- mask ratio: 4;
- overlap-mask training: enabled, matching Ultralytics default;
- single class: all three annotation categories collapsed to `filament`;
- canonical training population: 566 physical files represented by all 937 annotator records / 6,606 instances;
- canonical validation files are present only to satisfy dataset structure; training validation is disabled during the memory probe;
- one complete epoch, not a fractional smoke, so the highest-instance records and sustained allocator behavior are exercised;
- AMP and `expandable_segments:True`;
- no audit/test inference, submission export, or upload.

Feasibility passes only if the complete epoch finishes with no OOM and peak allocated memory remains below physical T4 capacity. A fractional smoke cannot authorize continuation because V18 already demonstrated that such probes miss late high-instance OOMs.

## Conditional full experiment

Only after feasibility passes, freeze a separate full run before training:

1. train YOLOv8l-seg at 2048/mask-ratio-4 with fixed checkpoints;
2. evaluate direct masks first using the public upstream inference rule (`conf=0.3`, `iou=0.0`) and confidence variants bounded before tune;
3. evaluate on canonical tune only with global organizer PQ over all annotator records;
4. compare against exact V17 counts and against the same checkpoint at 1024 inference to isolate native resolution;
5. require tune PQ >=0.50 to open audit, because incremental 0.45-class local candidates have repeatedly mapped to public 0.39;
6. require audit PQ >=0.50 before any test exporter;
7. submit only a structurally validated candidate that materially exceeds V17.

The feasibility script is `scripts/probe_v29_yolov8l_native2048.py`. It cannot read audit/test images or create a submission.
