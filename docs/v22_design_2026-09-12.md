# V22 design — COCO-initialized PointRend Mask R-CNN

Frozen **before training**, 2026-09-12. V22 is one bounded architecture experiment intended to break the V17 public 0.39 plateau without test-label leakage or leaderboard tuning.

## Hypothesis

The V17 family has two measured structural limits: the union of six YOLO proposal populations misses 212/1,134 tune instances (18.7%), and YOLO prototype masks impose a coarse-rendering wall. A two-stage RPN/RoIAlign detector can discover a different proposal population, while PointRend replaces uniform coarse mask rendering with adaptive predictions at uncertain points and outputs 224x224 RoI masks.

V22 therefore tests one coherent new family: **official COCO-pretrained PointRend Mask R-CNN R50-FPN**, fine-tuned only on approved competition annotations. It does not consume V17 proposals or predictions and is not another refiner, quality router, threshold extension, or YOLO continuation.

## Evidence

- Kirillov et al., *PointRend: Image Segmentation as Rendering*, CVPR 2020: uncertainty-biased point training and iterative subdivision produce 224x224 masks efficiently. Against standard 28x28 Mask R-CNN, R50-FPN PointRend improved COCO mask AP by +1.1 and AP evaluated on finer LVIS annotations by +2.1. Official implementation: <https://github.com/facebookresearch/detectron2/tree/main/projects/PointRend>.
- He et al., *Mask R-CNN*, ICCV 2017: learned RPN proposals plus quantization-free RoIAlign; alignment gains are largest at stricter mask IoU. <https://arxiv.org/abs/1703.06870>.
- Ahmadzadeh et al., *Toward Filament Segmentation Using Deep Neural Networks*, 2019: direct Mask R-CNN precedent on full-disk H-alpha solar filaments and an explicit requirement for high-resolution masks to preserve spines/barbs. <https://arxiv.org/abs/1912.02743>.
- Kirillov et al., *Panoptic Segmentation*, CVPR 2019: PQ uses strict IoU >0.5 matching and factors into segmentation quality and recognition quality. <https://arxiv.org/abs/1801.00868>.
- MORDEN, *A Modern ConvNet for Solar Filament Detection*, 2026: solar filaments are a low-contrast, multiscale, long-tail dense-prediction problem. <https://arxiv.org/abs/2607.24525>.

PointRend is not guaranteed to fix recognition recall; the experiment is justified because the RPN proposal family is also new. The result must separately report TP/FP/FN, matched mean IoU (SQ), and RQ.

## Data contract

Reuse the audited V20 COCO conversion because it preserves every independent annotator record while keeping physical filenames split-isolated:

| split | files | annotator records | annotations |
| --- | ---: | ---: | ---: |
| train | 566 | 937 | 6,606 |
| tune | 94 | 150 | 1,134 |
| audit | 47 | 67 | 459 |

Images use the already verified robust per-image solar-disk normalization: nonzero grayscale p2-p98 to uint8, replicated to BGR. No MAGFiLO public archive, test annotations, temporal test patching, AHAS/MHAS labels, solar-specific external weights, or opaque payload is permitted. The only external weights are the official public COCO PointRend R50-FPN checkpoint.

## Frozen model and training

- Detectron2 PointRend R50-FPN, official `pointrend_rcnn_R_50_FPN_1x_coco` architecture.
- Official COCO PointRend initialization pinned by SHA-256 before training. Incompatible 80-class predictor tensors are expected to be reinitialized for one class; backbone, FPN, RPN, box and shared mask features retain compatible pretrained tensors.
- One filament class; class-specific ROI and PointRend heads both set to one class.
- Fixed 1024x1024 model input; bitmask targets; standard official FPN anchors retained to preserve pretrained RPN weights.
- PointRend output 224x224: five subdivision steps, 784 uncertain points per step; 196 uncertainty-biased training points per RoI, oversample ratio 3, importance ratio 0.75.
- Four T4 GPUs, one image/GPU, global batch 4; AMP.
- SGD, base LR 0.0025, momentum 0.9, weight decay 1e-4; 200-iteration warmup; steps at epochs 15 and 18.
- 20 epochs = 4,700 global steps; deterministic seed 42.
- Checkpoints only at epochs 5, 10, 15, and 20.
- Standard horizontal flip augmentation only. No unregistered augmentation or post-hoc training extension.

## Resource gates

1. One forward/backward smoke on the densest 26-instance record. Abort on non-finite loss, load failure, or peak allocation >14 GiB on a 16 GiB T4.
2. A 100-global-step four-GPU timing probe. Abort if projected total exceeds six hours or any rank fails.
3. Resume that exact probe checkpoint to step 4,700; do not restart with changed settings.

## Frozen evaluation

For each fixed checkpoint, run native competition PQ on the canonical tune records. Predictions are sorted by model confidence and converted to disjoint masks by existing pixel ownership; residual area must be >=20.

- Confidence grid: `{0.05, 0.10, ..., 0.50}` only.
- Box NMS: 0.5, fixed.
- Maximum detections/image: 100, fixed.
- Select checkpoint/confidence by tune PQ only; deterministic tie-break prefers higher confidence, then earlier checkpoint.
- Open audit exactly once for the selected pair.
- Report PQ, SQ, RQ, TP, FP, FN, and IoU sum on both groups.

## Gates and submission policy

- **SUBMIT_BAR:** tune PQ >= **0.448703** and audit PQ >= **0.470763** (V17).
- **PROMOTION_GATE:** tune PQ >= **0.55** with audit still above V17.
- A CSV may be generated only if both SUBMIT_BAR conditions pass.
- No Kaggle upload is automatic. A validated, non-duplicate CSV still requires explicit authorization and a live quota check.
- If either bar fails, V22 is closed. No extra epochs, widened threshold grid, changed anchors, or public measurement without a new mechanism-specific hypothesis.

## Interpretation

A useful breakthrough must improve RQ materially rather than only polishing boundaries. PointRend can raise SQ, but the new RPN must also reduce V17's FN wall. If tune improves but audit does not, the architecture is not promoted. If both clear V17, test export is justified; only a large local margin is expected to be visible on the two-decimal public leaderboard.

## Completion result — 2026-09-12

V22 completed the exact frozen protocol after two controller/provenance defects were found and corrected during preflight. A first probe completed its optimizer steps but non-main ranks attempted to read rank-0-only metric history; a later continuation exposed an off-by-one caused by manually reserializing the framework checkpoint. Both invalid artifact directories were archived and never evaluated. The final run used Detectron2's own end-of-probe checkpoint byte-for-byte, whose outer/trainer/raw counters all equal 99, then resumed at exactly iteration 100.

Final execution:

- smoke on the densest 26-instance record: loss 7.5443, peak 1.5645 GiB;
- corrected four-T4 probe: 100 steps, 0.434 s/global step, projected 0.567 h, peak 2.562 GiB;
- continuation: exactly 4,600 steps from 100 to 4,700, 1,812.94 s, peak 2.565 GiB;
- all fixed checkpoint counters verified at iterations 1,174 / 2,349 / 3,524 / 4,699.

**Conclusion:** PointRend's high-resolution rendering did not break the wall because recognition remained limiting. Tune SQ reached only 0.6487 while FP remained 624 and FN 475. V22 is slightly below V20 on tune (-0.004473) and slightly above it on audit (+0.005784), but both are materially behind V17. Do not extend confidence beyond 0.50, add epochs, change anchors, export, or submit this checkpoint without a new mechanism-specific hypothesis. Any region-based follow-up must first demonstrate substantially better filament proposal classification/recall; more mask-resolution work alone is not justified.
