# V31 design — native-tile expert-spine SDT

Frozen **2026-09-13 before implementation, target generation, or GPU training**.

## Hypothesis

The current models discard the expert spine polyline attached to every filament. For masks with median effective width ~11 px, box/prototype/boundary representations can miss the object or break a thin connection and fall below strict IoU>0.5. A skeleton-aware distance transform (SDT) trained at native tile resolution should preserve each filament's connectivity while keeping adjacent boundaries separable.

Primary claim to test:

> Under an identical model, data population, schedule, and decoder, replacing standard boundary distance-transform targets with official expert-spine SDT targets improves canonical global tune PQ by at least 0.01, replicates at a second seed, and can reach PQ 0.50.

## Targets

### Shared rasterization

Rasterize every polygon with `pycocotools`, preserving all polygon components. Rasterize and densify the associated expert spine polyline. Due to polygon/polyline rounding differences, project each sampled spine point to the nearest foreground pixel within a frozen radius of 3 px; ignore a point if no foreground exists in that radius. Record projection distances and reject target generation if fewer than 95% of annotations retain at least two valid spine points.

Exact overlap pixels between different instances in one annotator record are excluded from loss. This affects only five of 1,154 labeled records in the complete dataset.

### Control: standard DT

For every instance pixel, compute distance to its nearest instance boundary, normalize per instance to [0,1], and combine non-overlapping instances into one energy map. This is the matched representation control.

### Arm: expert-spine SDT

For every instance and pixel `x`:

`E(x) = (d(x, boundary) / (d(x, spine) + d(x, boundary) + 1e-6))^0.8`.

Energy is zero at boundaries and one along the projected expert spine. Quantize foreground energy into ten equal-width bins; class zero is background. Targets are generated after spatial transforms so cropped/rotated geometry remains consistent.

An auxiliary one-channel spine heatmap is trained in both arms. In the control it uses a morphology-derived local skeleton; in the SDT arm it uses the official projected spine. Its loss weight is fixed at 0.20 and it is used only to stabilize learning, not as an additional tuning lever.

## Native-tile dataset

- input tile: 1024×1024 at native pixels;
- tile origins per 2048 image: Cartesian product of `{0, 512, 1024}`;
- training population: all positive owner tiles plus 540 deterministic SHA-ranked empty tiles, reconstructed independently per annotator record;
- no full-frame resized samples in the primary experiment;
- grayscale copied to three channels;
- per-tile robust p1–p99 normalization, calculated from that tile only;
- augmentations: horizontal/vertical flip, 90-degree rotation, brightness/gamma, and mild Gaussian noise; no elastic deformation because it can invalidate expert spine/body correspondence;
- split and target manifests must include source hashes and tile ownership.

## Model

Use `torchvision` DeepLabV3 with a ResNet-50 ImageNet backbone, output stride 8, and a replaced classifier:

- 11 SDT/DT classes;
- one auxiliary spine-logit head;
- bilinear output to 1024 before loss;
- mixed precision;
- no solar pretrained weights.

This follows the SDT paper closely while avoiding a new model-family confound. If the full-population smoke exceeds the memory gate, reduce only batch size to one; resolution cannot be lowered in V31.

## Matched four-arm training

Run one model per T4 concurrently:

| GPU | representation | seed |
| ---: | --- | ---: |
| 0 | standard DT control | 42 |
| 1 | expert-spine SDT | 42 |
| 2 | standard DT control | 20260913 |
| 3 | expert-spine SDT | 20260913 |

Frozen optimizer/schedule:

- AdamW, learning rate 1e-4, weight decay 1e-4;
- 1,000-step linear warmup, cosine decay;
- batch one per GPU, gradient accumulation four;
- exactly 20,000 optimizer steps;
- checkpoints at 5k/10k/15k/20k;
- no early stopping and no checkpoint choice from training loss.

## Global inference and instance decoding

For each physical image:

1. predict all nine native 1024 tiles;
2. blend pre-softmax logits into a 2048 canvas using a raised-cosine window with nonzero edge floor;
3. softmax once globally;
4. recover expected energy from the ten foreground bins;
5. define foreground from `1 - P(background)`;
6. create seeds as connected components above the seed-energy threshold;
7. apply watershed to reversed expected energy, constrained to foreground;
8. fill holes, remove masks below 20 px, and enforce deterministic disjoint ownership.

The only tune grid is the predeclared Cartesian product:

- foreground probability: `{0.35, 0.45, 0.55}`;
- seed energy: `{0.65, 0.75, 0.85}`;
- nine candidates per checkpoint;
- minimum area fixed at 20;
- no TTA, dilation, erosion, component splitting, confidence blending, or per-image adaptation.

Selection is by canonical global tune PQ only. Ties choose the higher foreground threshold, then higher seed threshold, then earlier checkpoint.

## Gates

### G0 — contamination and population

Before target generation:

- exact fit/tune/audit populations match frozen counts;
- no competition test path exists in the runtime;
- no public MAGFiLO annotation hash/path exists;
- every fit annotation has a nonempty spine;
- all source hashes are recorded.

Failure closes V31.

### G1 — target-oracle decode, CPU only

Decode exact SDT and DT target maps before training. On all fit/tune records require:

- PQ >=0.97 against source polygon masks;
- instance recall at strict IoU>0.5 >=0.99;
- no unexplained instance merge/split concentration;
- projected-spine validity >=95%.

Failure means the representation/decoder is invalid; no GPU run is allowed.

### G2 — numerical overfit

Overfit 16 fixed fit records for at most 2,000 optimizer steps. Require decoded training PQ >=0.85 and finite losses. This is a target/network wiring test, not evidence for promotion.

### G3 — full-population resource smoke

Run one complete pass over the frozen tile population for all four arms. Require:

- finite forward/backward and checkpoint reload;
- external peak memory <14,336 MiB per T4;
- projected 20k-step wall time <=4 hours;
- identical sample counts and ordering within matched seeds.

No weakening after observation.

### G4 — tune mechanism and replication

Evaluate every frozen checkpoint and nine-cell candidate on exactly 94 files / 150 records / 1,134 GT. The evaluator must first reproduce V17 at PQ 0.44870271727943206 and counts 704/306/430.

The SDT hypothesis is supported only if:

- primary SDT PQ >=0.458703 (V17 +0.010);
- primary SDT minus matched DT >=+0.010;
- primary SDT TP >=704 and FP <=356;
- replica SDT minus matched DT >0;
- both SDT seeds beat V17 or are within 0.005 with seed spread <=0.015.

If these mechanism gates fail, close V31 without audit. They do not authorize audit by themselves.

### G5 — audit authorization

Audit opens exactly once only if tune-selected primary SDT reaches **PQ >=0.50** and the replica SDT also beats V17. Freeze checkpoint and both thresholds before opening audit.

Submission export is authorized only if:

- audit PQ >=0.50;
- audit does not regress below V17 audit 0.470763;
- tune and audit both have SQ >=0.68;
- structural output validation passes.

No full-data refit is part of V31. Submit the exact held-out model that passed the gates.

## Submission path

If and only if G5 passes:

1. run exact frozen SDT checkpoint on all 180 test images with the same nine-tile blending and frozen thresholds;
2. emit sequential `filament_id` values and compressed COCO RLE;
3. independently validate known IDs, full decoding, area >=20, and zero within-image overlap;
4. write SHA-256 manifest and immutable submission package;
5. upload exactly once with the Kaggle CLI;
6. record submission ID, CSV hash, and public score.

## Stop rules

Do not rescue V31 with:

- public MAGFiLO labels or opaque solar weights;
- lower resolution;
- extra epochs/steps;
- broader threshold grids;
- alternate alpha or bin count;
- clDice/flow/orientation losses added after tune;
- audit inspection after a failed tune gate;
- blending with V17/V26/V29/V30 after seeing tune;
- test inference or upload without G5.

If V31 fails G1/G2, implement Omnipose as the next representation study. If V31 learns targets but fails G4, the next clean architecture study is RF-DETR-Seg/MaskDINO—not another SDT hyperparameter sweep.
