## Efficiency Notes

- The local VM currently has no usable NVIDIA driver: `nvidia-smi` cannot communicate with the driver.
- Because local GPU training is unavailable, the efficient path is to run training on Kaggle GPU and use the VM for orchestration, documentation, and submission.
- The public reference notebook reported a 33m35s runtime on T4 x2 for a similar YOLO + refiner approach.
- Our V3 kernel requests T4 and runs 30 YOLO epochs plus 8 refiner epochs and a confidence sweep. Expected runtime is roughly 35-60 minutes depending on assigned GPU and Kaggle queue behavior.
- Inference is efficient because YOLO proposes instances directly at 1024px, and the refiner only processes small crops rather than the full 2048 x 2048 disk repeatedly.
