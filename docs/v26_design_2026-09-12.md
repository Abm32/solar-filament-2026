Frozen before implementation or GPU inference on 2026-09-12.

Four-GPU tune evaluation merged the exact 94 files / 150 annotator records / 1,134 GT and reproduced V17 control exactly at PQ 0.44870271727943206 (704 TP / 306 FP / 430 FN). The hybrid selected `iou030/t0.45_c0.45` at PQ **0.432869** (678 / 339 / 456), while sliced-only selected PQ 0.407919.

Raw-recall, historical-rescue, bottom-recall, and FP gates passed; absolute and matched-control PQ gates failed.

## Hypothesis

The remaining structural wall is small-instance proposal discovery. Every deployed YOLO detector sees a 2048×2048 full disk resized to 1024 or less, halving each filament's linear pixel extent before the backbone. V18 proved that native/high-resolution mask-ratio-1 training does not fit a T4, but it did not test tiled inference. V26 preserves native pixels with overlapping 1024×1024 slices while retaining V17 full-frame inference for the few large objects that do not fit a slice.

This is not the untrained semantic tiling proposed by recent public EDA notebooks. It is sliced instance-proposal inference using the strongest validated V17 detector and the unchanged V17 refiner/PQ pipeline.

## Evidence

### Project measurements

On the 1,134 canonical tune GT instances:

- V6 has 228 instances with no raw proposal at IoU >0.5;
- their median area is 826.5 px;
- 112/228 lie in the bottom 30% by area;
- 226/228 fit wholly inside the deterministic owner among overlapping native 1024 tiles;
- 213/228 fit wholly in multiple tiles;
- across all GT, 1,130/1,134 fit their owner tile.

Thus the geometry covers nearly the entire measured invisible-instance population. The four owner failures are large objects, exactly what the retained full-image branch is for.

No existing project run implemented native sliced YOLO inference. Prior mentions were proposals only. V12 changed full-frame detector resolution; V18 attempted full-frame high-resolution training and OOMed; V19 discussed Mask2Former sliding windows but never implemented them.

### Primary literature

Akyon et al., *Slicing Aided Hyper Inference and Fine-tuning for Small Object Detection* (2022), <https://arxiv.org/abs/2202.06934>, report +5.1 to +6.8 AP from sliced inference without retraining and +12.7 to +14.5 cumulative AP with sliced fine-tuning. Their mechanism is directly applicable: overlapping patches increase small-object pixel coverage while bounding memory, and optional full-image inference preserves large-object performance. Their experiments also show overlap improves small/medium AP while full inference contributes to large-object AP.

The paper uses bounding-box AP, not solar instance PQ; V26 therefore requires raw mask recall and final canonical PQ gates rather than assuming transfer.

## Frozen slicing geometry

For each original 2048×2048 image:

- tile size: 1024×1024;
- x/y starts: `{0, 512, 1024}`;
- tiles: 3×3 = 9;
- overlap: 512 px (50%);
- detector input size: 1024, so tile pixels are not downsampled;
- full branch: original image at V17's 1024 inference size.

Every branch uses four V17 flip views, `retina_masks=True`, detector confidence floor 0.10, and box IoU cells `{0.3, 0.7}`. Tile masks are restored from flip coordinates, embedded into the 2048 canvas, and cached with identities spanning checkpoint, branch, tile origin, cell, image, view policy, and inference size.

## Deterministic ownership and duplicate control

A tile prediction is assigned by its global mask centroid to the nearest tile center independently on each axis. Tile centers are `{512, 1024, 1536}`; midpoint ownership boundaries are 768 and 1280. Only a prediction generated by its owner tile is retained. Global-image edges are naturally owned by the outer tiles.

This policy is label-blind and frozen before inference. Ground-truth geometry audit shows the owner tile fully contains 226/228 exact raw misses and 1,130/1,134 total GT instances. Ownership avoids counting the same central object from multiple overlapping tiles while allowing the full branch to handle the four owner-noncontained large instances.

After per-tile four-view consensus and ownership:

1. map every retained tile RLE to full-image coordinates;
2. cross-tile mask NMS at IoU >=0.50, retaining the higher detector score;
3. merge with the full-image proposal population;
4. cross-branch mask NMS at IoU >=0.50, retaining the higher detector score;
5. pass proposals to the unchanged V17 refiner using original full-resolution raw pixels;
6. apply the frozen constrained ownership/minimum-area postprocessor.

No box-only merge, mask union, averaging, morphology, split/bridge logic, or score boost for tile detections is allowed. Tile and full detector scores remain as emitted by the same checkpoint.

## Canonical evaluation

Tune first on the same 94 files / 150 annotator records / 1,134 GT. For every arm/cell report:

- raw proposal recall at strict IoU >0.5;
- raw mean/max/p90 best IoU;
- exact count of V17-control raw misses rescued by a sliced proposal;
- proposal count before/after ownership and NMS;
- final PQ/SQ/RQ/TP/FP/FN;
- area-decile recall, especially the bottom 30%.

The final grid is unchanged from V17:

- refiner thresholds `{0.35, 0.40, 0.45, 0.50, 0.55, 0.60}`;
- final confidence `{0.25, 0.30, 0.35, 0.40, 0.45, 0.50, 0.55}`;
- strict IoU >0.5 global PQ over every annotator record;
- minimum area 20 and disjoint pixel ownership.

The control must reproduce V17 tune PQ 0.448703 within 1e-6 and its exact TP/FP/FN counts before an arm is trusted.

## Four-GPU execution

No training is required. Partition tune physical files deterministically into four lexicographic shards, one per T4. Each GPU evaluates full and tile branches for its shard and writes atomic branch caches/results. Merge asserts:

- each of 94 tune files appears exactly once;
- every cache signature/hash matches;
- shard populations sum to 150 annotator records / 1,134 GT;
- no audit/test path was opened;
- control counts reproduce V17 exactly.

A four-file smoke (one file per GPU) must first prove tile remapping, flip inversion, ownership, NMS, refiner geometry, deterministic cache replay, and projected full tune wall time <=3 hours. Memory must remain below 15,872 MiB per T4.

## Stop rules

Close V26 without audit if any gate fails. Do not change tile size, overlap, ownership boundaries, NMS IoU, confidence floor, flip policy, thresholds, refiner, or gate values after tune. Do not add CLAHE, V24/V25 checkpoints, semantic masks, support weighting, or a tile confidence boost. Do not inspect audit to select tile geometry.

If V26 fails raw-recall gates, native slicing does not expose the invisible instances and the mechanism is closed. If raw recall passes but PQ fails, sliced proposals are not separable from FP under the validated refiner; close rather than tune post hoc.
