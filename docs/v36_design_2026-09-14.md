# V36 design — RF-DETR-Seg-Nano Azure-T4 portability gate

Frozen **2026-09-14 before V36 implementation, dependency installation, or model execution**.

## Decision and separation from V35

V36 is a separately numbered hardware-portability experiment for the strongest remaining clean architecture, not a post-hoc quality rescue. V35 established that official RF-DETR-Seg-Nano can complete its one-epoch Solar fit-only smoke within the resource envelope, but its corrected immutable Kaggle runs were assigned unsupported P100 accelerators instead of the requested T4. The corrected fixed-resolution contract was therefore never evaluated.

V36 moves that unchanged scientific question to the already allocated Azure `rogii-gpu` host, whose four GPUs were independently verified as idle Tesla T4 16,384 MiB devices with compute capability 7.5. It does not change the model, data, resolution, mask grid, optimizer, threshold grid, gates, or contamination policy.

## Why this architecture is the breakthrough candidate

V17 is locally PQ 0.448703 with 704 TP / 306 FP / 430 FN and public 0.39. Six YOLO proposal sources still miss 212/1,134 tune instances, and their zero-FP union oracle is only PQ 0.5849. Small area drives misses; downstream refinement and score calibration cannot discover invisible instances.

RF-DETR-Seg-Nano is the highest-ranked executable architecture because it jointly replaces YOLO proposal discovery and coarse prototype masks with:

- detection-aware DINOv2/deformable query features;
- generic COCO instance-segmentation pretraining;
- 100 learned object queries;
- a 384x384 learned mask grid at the frozen 768 input;
- an official maintained implementation benchmarked on T4.

Mask Frozen-DETR is the fallback: its paper reports strong small-object mask AP and one-16GB-GPU training, but it freezes detector discovery and requires a separate detector/mask-head integration. MaskDINO lacks safe T4 headroom. SDT/Omnipose image models and the tested region/semantic architectures have already failed their gates.

## Data firewall

Allowed:

- exactly 16 canonical fit annotator records;
- exactly nine referenced official fit JPEGs;
- 57 source annotations;
- identical aliases for RF-DETR train/valid/test directory syntax, with `run_test=false`.

Forbidden through G2:

- canonical tune records;
- sealed audit records;
- competition test images;
- public MAGFiLO labels, which overlap competition test filenames;
- any Solar checkpoint or prediction payload;
- CSV generation, export, or submission.

The runtime must report all five forbidden actions as false.

## Isolated Azure environment

V36 uses `/mnt/solar-v36-rfdetr` and must not modify the shared repository virtual environment. Create a dedicated virtual environment inheriting the host's CUDA-compatible Torch 2.4.1 / torchvision 0.19.1, then install the hash-pinned RF-DETR wheel and pinned training dependencies. Record all resolved versions. Installation must not replace Torch or torchvision.

GPU execution is restricted to `CUDA_VISIBLE_DEVICES=0`. Before model construction require:

- visible GPU name contains `T4`;
- compute capability is 7.5;
- no pre-existing project GPU process;
- canonical data and all package/checkpoint hashes match;
- fixed `multi_scale=false`, `scale_jitter=false`, and no custom augmentation.

Failure before model execution is an infrastructure failure and cannot authorize G2.

## G1 — corrected fixed-resolution resource smoke

Run exactly one epoch / 16 optimizer steps:

- `RFDETRSegNano`, one class, 100 queries;
- resolution 768;
- `mask_downsample_ratio=2`;
- batch size 1, accumulation 1;
- learning rate `1e-4`;
- gradient checkpointing on;
- EMA and early stopping off;
- fixed square resize, no multi-scale or scale jitter;
- validation once at epoch end;
- checkpoint save, reload, and one prediction from deterministic alias `01_030101-20110109104734Ch.jpeg`.

G1 passes only if:

- the accelerator identity is an Azure Tesla T4;
- all train/validation losses found in `metrics.csv` are finite;
- at least one optimizer epoch completes;
- external peak GPU memory is in `(0, 14,336)` MiB;
- elapsed model-run time is <=1,200 seconds;
- a checkpoint reload and prediction call succeed;
- pretraining load has no partial-load error beyond the expected one-class detection-head reset;
- the data firewall remains intact.

No model-quality conclusion is permitted from one epoch.

## Conditional G2 — bounded memorization gate

Only a passing V36 G1 authorizes implementation and launch of G2. G2 retains the same identities and 16 records and runs at most 2,000 optimizer steps (125 epochs). Evaluate checkpoints 25/50/75/100/125 with confidence `{0.05,0.10,0.20,0.30,0.50}` using deterministic one-to-one maximum-IoU matching and strict IoU >0.5 at source resolution.

G2 passes only if one frozen checkpoint/cell reaches all of:

- PQ >=0.85;
- recall >=0.90;
- median matched IoU >=0.80;
- finite losses and outputs;
- peak memory <14,336 MiB;
- <=2,000 optimizer steps;
- zero forbidden reads/exports/submits.

Failure closes this RF-DETR configuration. Do not change model size, resolution, mask ratio, query count, thresholds, losses, augmentation, or step budget after observation.

## Conditional full experiment and submission bar

Passing G2 authorizes only a new full-population design. A later full run must use canonical 566-fit / 94-tune / sealed-47-audit populations, matched seeds, and contamination-safe generic pretraining. Audit remains sealed until primary tune PQ >=0.50 and replication is above V17. Test export requires audit PQ >=0.50 and no regression versus V17. Only a fully validated candidate clearing those gates can be submitted once.

## Stop rules

- Do not use the local RTX 3050 4GB for training.
- Do not install into or mutate the shared Azure project environment.
- Do not use more Azure GPUs to accelerate G1/G2; these gates are intentionally single-T4 and bounded.
- Do not use public Solar labels/checkpoints or competition test images.
- Do not reinterpret Kaggle P100 failures as model evidence.
- Do not upload V17 again or create a new submission before the full tune/audit gates pass.
