# V15 design — retest the mask-quality hypothesis with a working encoder

Written **before** the run, 7 September 2026, after diagnosing V14 (E025).
Supersedes the "detector `mask_ratio=1` next" recommendation in
[`ceiling_analysis_2026-09-07.md`](ceiling_analysis_2026-09-07.md) §8.

## Why this run exists

V14 measured **three of its own defects**, not its hypotheses. All three are in
`kaggle_inference/v14_dualhead.py` / `v14_runtime.py` and all three are cheap to fix:

| # | defect | consequence |
| --- | --- | --- |
| 1 | `DualHeadRefiner(pretrained=warm_start is None)` — supplying a warm start **disabled ImageNet init**, and the ResNet18→ResNet34 warm start transferred only **131 of 298** tensors | the encoder was mostly **random** for 8 epochs; meanIoU regressed to 0.6604 vs V13's 0.6855 |
| 2 | the IoU head trained only on `build_training_cohort` records, which are **positive-matched only** (`min_iou=0.30`) | head emitted a near-constant ~0.62–0.66; every declared `iou_gate` filtered **0 of 1773** proposals; FP 309 → **2051**; tune PQ **0.2449** |
| 3 | `zip(predicted_iou[:len(actual)], actual)` misaligned raw proposal order against the sorted/filtered built order | reported AUC 0.5087 measured the misalignment, not the head |

Because of defect 1 the expensive question — **can a higher-capacity mask head move
mean matched IoU off 0.686?** — was never actually asked. That question, not the
detector, is what V15 re-asks. `ceiling_analysis` item 1 is **untested**, not
falsified, and E-F/Focal-Tversky is **not** retired (arm_b lost to arm_a, but both
sat on a crippled encoder, so the loss comparison is confounded by initialisation).

## The central design decision: keep V13's proven selection

V14 replaced detector confidence with a learned gate **and** changed the mask head in
the same run. When the gate failed, the mask change became unmeasurable. V15 does not
repeat that: it changes **only the refiner** and keeps V13's exact, measured selection
mechanism.

```
V13 (0.441777 tune, public 0.39) = E-A box iou=0.3 proposals
                                 + V11 proposal_centered_e4 refiner (ResNet18)
                                 + threshold x confidence grid, refined_constrained

V15                              = E-A box iou=0.3 proposals            [UNCHANGED]
                                 + V15 dual-head refiner (ResNet34, ImageNet init)
                                 + threshold x confidence grid          [UNCHANGED]
```

Confidence gating at `c0.30` is what held V13 to FP=309. Retaining it means V15
**cannot** reproduce V14's FP explosion, which is the single largest risk retired.
The learned IoU score is still computed and reported, but it **does not select** —
it is recorded as a keep-fraction frontier for a future run to act on.

Selection is therefore over V13's frozen grid: `THRESHOLDS` (0.35…0.60) x
`CONFIDENCES` (0.25…0.55) = **42 predeclared candidates**, bound at runtime to
`detector_tta.LOCAL_*` exactly as V13 does.

## Fixes, each with its verification

1. **ImageNet init, unconditionally.** `resnet34(weights=ResNet34_Weights.DEFAULT)`
   regardless of warm start; the warm start is then layered on top for
   shape-matching tensors only. The run **asserts** `pretrained=True` was used and
   logs the transferred/skipped counts, and a test asserts the encoder's stem
   weights differ from a `weights=None` construction.
2. **Negatives in the scoring cohort.** The mask cohort stays byte-identical to
   V11/V14 (`cohort_sha256` pinned) so the mask objective is unchanged and
   comparable. The **scoring** head additionally sees unmatched grouped proposals
   with their true IoU against GT (mostly ~0). Target stays "IoU of my own mask vs
   GT", so it is the same quantity, just measured over the population the head
   actually meets at inference. Asserted: the scoring cohort must contain
   **≥20% negatives** (`true_iou < 0.1`), else the run raises rather than shipping
   another constant head.
3. **Aligned diagnostic.** `instances_for_candidate` returns the surviving proposal
   indices, and the head rows are built from those indices, so predicted and actual
   refer to the same instance. Asserted: a permutation test where a deliberately
   shuffled score array must drop the reported AUC to ~0.5.
4. **Scale-invariant reporting.** The learned score is reported as a **keep-fraction**
   frontier (top 10%…100%), never as an absolute cut, so a head with any output
   range still produces a meaningful curve. Absolute gates were the vector for
   defect 2.

## Predeclared bars, fixed before any V15 number is observed

- **SUBMIT_BAR** (authorises exporting a CSV): tune ≥ **0.441777** (V13) **and**
  audit ≥ **0.450130** (E015 floor).
- **PROMOTION_GATE** (authorises calling it a real gain): tune ≥ V13 + **0.010**
  with audit ≥ V13's 0.464644.
- **Frozen control first.** The control must reproduce E015's counts
  (tune `[426.5473399071962, 626, 211, 508]`) and its exported CSV must hash to
  `bf11690e9bcce73b0c627096cc1198d9fb0916650f7fa4b3f08f1167bb76bde9`. Abort otherwise.

Submission policy, given E024's evidence that +0.0038 local was invisible publicly:
**export at SUBMIT_BAR, but only spend a submission if the margin over V13 is large
enough to be visible at two decimals** (≥ +0.010 tune, i.e. the promotion gate). A
candidate that clears SUBMIT_BAR but not the gate is recorded, not uploaded.

## Honest expectation

The mechanism is narrow and the claim is correspondingly modest: V15 asks whether a
*properly initialised* ResNet34 U-Net with deep supervision beats a ResNet18 U-Net at
refining the same proposals under the same selection. V11's ResNet18 continuation
bought +0.005177 tune. If capacity matters at all, meanIoU should exceed 0.6855;
if it does not, the mask-capacity lever is closed for real this time and the detector
cap (`mask_ratio=1`) becomes the remaining candidate on solid evidence rather than on
a run with a random encoder.

Two outcomes are both informative:

- meanIoU > 0.6855 → capacity is a lever; scale it and revisit the learned gate with
  the frontier this run measures.
- meanIoU ≤ 0.6855 with a verified ImageNet encoder → `ceiling_analysis` item 1 is
  genuinely falsified, and the 0.873 raw-proposal cap is the only axis left.

Cost estimate ~3,400–4,000 GPU-s (V14's 8-epoch two-arm run cost 3,413 s; V15 trains
**one** arm, so the training half roughly halves while evaluation over 42 candidates
grows). Quota is 68,338 s, refreshing 2026-09-12.
