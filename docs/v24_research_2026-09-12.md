# V24 research note — incomplete multi-rater supervision

## Finding

The strongest untested project-specific mechanism is not another architecture. It is contradictory supervision created by presenting multiple incomplete annotations of the same pixels as independent fully labeled images.

On the frozen 566-file training split:

- 248 files have multiple annotators;
- those files contain 619 records and 4,158 raw annotations;
- naïve cross-rater IoU>0.5 clustering yields 2,678 instance groups;
- 1,559 groups (58.2%) have support from only one annotator;
- 191 files contain more groups than the most complete individual rater target.

Therefore, the current all-annotator loader frequently presents a filament as foreground in one iteration and background in another. This mechanism predicts reduced absolute confidence and missed faint/small objects, consistent with both the literature and this project's cutoff/recall decomposition.

## Why this outranks alternatives

- More YOLO resolution is infeasible on T4 with mask_ratio=1; detector image resolution already failed as a lever.
- PointRend improved rendering but retained excessive FP/FN.
- CondInst's semantic branch and dynamic masks remained far below V17.
- Mask2Former, proposal unions, threshold drops, CLAHE, refiner capacity, and full-data refit are closed.
- Missing-label correction directly changes which regions receive negative gradients and can create proposals for the 212 instances every current pool misses.

## Relevant primary evidence

1. Wu et al. (2019), Soft Sampling: unlabeled true objects generate incorrect background gradients; missing labels depress scores, and overlap-aware gradient weighting recovers detection performance.
2. Zhang et al. (2020), Background Recalibration Loss: one-stage dense detectors are particularly vulnerable; recalibrating confusing negative gradients improves VOC and COCO under missing annotations.
3. Pham et al. (2023), multi-expert object detection: consensus fusion plus agreement weighting improves over using all annotations as ordinary ground truth.
4. Campi et al. (2026), multi-rater detector calibration: explicitly representing rater disagreement improves calibration compared with mixed-label sampling.

## Bounded implementation choice

A custom YOLO loss modification would introduce both target and optimizer changes and make attribution difficult. V24 first tests the cleaner upper-bound intervention available from the labels themselves: construct one complete physical-image target while retaining original mask geometry. Constrained clusters prevent transitive bridge-merges, and medoids prevent synthetic shape artifacts.

This is an experiment, not a claim that every singleton annotation is correct. Tune PQ, raw recall, replication, and audit gates price the false-positive risk.
