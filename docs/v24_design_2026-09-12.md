## Result sought

V17 remains the only 0.39 submission. Six stored YOLO proposal populations jointly miss 212/1,134 tune instances, and small/faint instances dominate false negatives. V19/V20/V22 showed that swapping to Mask2Former, CondInst, or PointRend does not solve this recognition wall. V23 preprocessing was stopped at its resource gate.

V24 tests a training-target defect that has not been measured: the current all-annotator loader repeats each physical image with each rater's incomplete target independently. When rater A labels a filament omitted by rater B, the rater-B copy presents that same real filament as background. This can suppress confidence while preserving approximate localization—the exact pattern reported for missing-annotation detectors and observed in this project.

## Train-only audit

The frozen V6 split has 566 train physical files and 937 annotator records. Of those files, 248 have multiple annotators. Their 4,158 raw annotations form 2,678 naïve cross-rater IoU>0.5 components; 1,559 (58.2%) are supported by only one annotator, and 191 files have more components than any single rater labeled. Thus disagreement is predominantly omission, not only boundary variation.

One transitive component contained two instances from the same rater. V24 therefore uses constrained descending-IoU clustering: components merge only when their rater sets are disjoint. This produces 5,127 physical-image targets across all 566 files. Repeating the same complete physical target over the unchanged 937 records produces 9,265 training labels. The control retains the original 6,606 incomplete labels.

## Evidence

- Wu et al., *Soft Sampling for Robust Object Detection* (2019), <https://arxiv.org/abs/1806.06986>: missing objects become incorrect background supervision; soft sampling recovered much of the missing-label performance gap and improved Open Images by over 3%.
- Zhang et al., *Solving Missing-Annotation Object Detection with Background Recalibration Loss* (2020), <https://arxiv.org/abs/2002.05274>: one-stage detectors are especially exposed to dense incorrect negative gradients; BRL substantially improved curated VOC/COCO missing-label settings.
- Pham et al., *Improving Object Detection in Medical Image Analysis through Multiple Expert Annotators* (2023), <https://arxiv.org/abs/2303.16507>: aggregating multi-expert annotations and agreement-aware training outperformed all-annotation, individual-rater, and rater-ensemble baselines.
- Campi et al., *Leveraging Multi-Rater Annotations to Calibrate Object Detectors in Microscopy Imaging* (2026), <https://arxiv.org/abs/2601.23007>: mixed label sampling can obscure rater disagreement; explicit rater handling improved calibration without reducing detection accuracy.
- MAGFiLO (Ahmadzadeh et al., 2024) and project E028 provide the solar/task context: faint and small filament recall, not elongation, is the measured wall.

These papers support the mechanism, not a promised Kaggle gain. V24 uses only competition training annotations and pixels.

## Controlled comparison

Every arm warm-starts independently from the exact V17 primary detector:

`ae476e663039fbbbfda77ec519635ca15e2d50d1fe9f1af54735f84dbdc251ef`

| property | control | consensus arm |
| --- | --- | --- |
| physical train files | 566 | 566 |
| sample records/order weight | 937 repeated annotator records | identical 937 records |
| pixels | original competition JPEG | identical |
| targets | each record's original incomplete labels (6,606) | same physical consensus target for every repeated copy (9,265) |
| geometry | original polygons | one original medoid polygon per cluster |
| training | 20 epochs, 896px, batch 1, mask_ratio=1 | identical |
| seeds/GPUs | 42/GPU0; 20260912/GPU1 | 42/GPU2; 20260912/GPU3 |

No polygon union, averaging, dilation, synthetic label, external data, or pseudo-label is allowed. For each constrained cluster, the original annotation with highest mean IoU to other members is retained; annotation ID breaks ties. Single-rater clusters are retained because the hypothesis is specifically that omissions are real positives, and the evaluator itself scores each rater separately.

The control retains 937 records rather than collapsing to 566 so image frequency and optimizer-step budget remain matched. The only changed variable is target completeness.

## Resource protocol

1. Build both datasets and verify exact file/record/label counts and source hashes.
2. Run one full-population epoch concurrently on all four T4s. Random-fraction smoke is forbidden.
3. Require all jobs finite, all return codes zero, projected concurrent wall time <=3 hours, and external peak memory <15,872 MiB on every GPU (at least 512 MiB physical headroom).
4. If the gate passes, run all four fixed 20-epoch continuations concurrently. No retry with changed resolution, batch, labels, or schedule.

896px is used because V23 measured the 1024px mask-ratio-1 continuation above a conservative safety gate even at batch 1. V24 establishes its own predeclared physical limit against the 16,384 MiB T4 capacity and requires a full-population epoch before authorization.
