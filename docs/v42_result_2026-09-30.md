## Findings
1. Recall gate (>=0.90) and FP gate (<=40) now PASS by huge margins
   (best: recall 0.997, FP 1, FN 1 -> 307/308 GT matched).
2. RESOLUTION is the dominant lever for mask quality; model CAPACITY is not:
   at imgsz 1024, n/s/m PQ = 0.592/0.601/0.568; larger models are worse and
   yolo11m/l at 2048 exceed the 14,336 MiB memory gate (ext ~15.8 GiB).
3. Best config yolo11s-seg @ 2048 / 300ep: PQ 0.768, medIoU 0.781 — the two
   remaining gates (PQ>=0.85, medIoU>=0.80) are close but NOT passed. Gains
   flatten with resolution, so native-res mask refinement (TTA / mask-head
   refine / more epochs) is the next lever.
