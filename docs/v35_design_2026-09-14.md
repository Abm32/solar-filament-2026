# V35 design — RF-DETR-Seg-Nano query-instance feasibility

Frozen **2026-09-14 before V35 implementation, package installation, remote launch, or model output**.

## Architecture audit and selection

V35 is the remaining clean query-segmentation architecture study after V34. Two official families were audited.

### MaskDINO — rejected before implementation

Official MaskDINO is Apache-2.0 and materially different from failed V19 Mask2Former through detection-aware query selection, mask-enhanced box initialization, denoising, and joint box/mask matching. However, its official ResNet-50 recipe reports approximately **15 GB per GPU** at the published batch, while a Kaggle T4 exposes roughly 14.56 GiB. The official documentation leaves single-GPU batch/LR selection to the user; its Swin-L recipes require about 60 GB/GPU. This leaves no predeclared T4 safety margin and makes a faithful resource-gated run impractical here. MaskDINO is not launched.

### RF-DETR-Seg — selected

RF-DETR is maintained, Apache-2.0, built on DINOv2/Deformable-DETR, and provides official COCO-pretrained instance-segmentation Nano/Small variants benchmarked on T4. The current stable package is `rfdetr==1.10.1`; PyPI wheel SHA-256 is `96fa7a8ecbcaeea5f5150ff0b503699d2d4d75a32a87eeabfc0ab90485076a52`. Release 1.10.1 specifically reduces peak CUDA memory in segmentation loss.

Selected official checkpoint:

- logical name: `rf-detr-seg-nano.pt`;
- source: `https://storage.googleapis.com/rfdetr/rf-detr-seg-n-ft.pth`;
- vendor MD5: `9995497791d0ff1664a1d9ddee9cfd20`;
- independently measured SHA-256: `a44613a4ecd6b5ba61a62002c600b0b6cb7a9da2936a45317ec4b62c635fb99b`;
- size: 134,545,398 bytes;
- provenance: generic Microsoft COCO instance segmentation; no solar data.

No public solar RF-DETR checkpoint or prediction payload is permitted. The public competition RF-DETR notebooks were inspected only for API/resource evidence. Their labels, weights, predictions, proxy metrics, refiners, and split choices are not inputs to V35.

## Hypothesis

> A generic COCO-pretrained detection-aware query model with a 384px mask grid can numerically overfit 16 canonical solar fit records at native-source evaluation strongly enough to justify a separately frozen full-population experiment.

This is a wiring/learnability claim, not evidence for tune or public improvement.

## Non-negotiable data firewall

Allowed:

- hash-pinned official competition training JSON only;
- exactly the first 16 canonical fit annotator records ordered by sorted fit filename then image id;
- exactly the nine distinct official fit JPEGs referenced by those records;
- official Apache-licensed RF-DETR package and COCO checkpoint above.

Frozen selection identity: `e561c523b60993e93f82ce03116737ce512f54f4103b4557c29e409c88c92653`.

Forbidden:

- canonical tune or sealed audit records;
- any competition test image;
- public full-MAGFiLO annotations, which overlap 139/180 test names;
- any solar checkpoint or public prediction payload;
- CSV generation, export, or Kaggle submission.

The runtime must report `reads_tune=false`, `reads_audit=false`, `reads_test=false`, `exports=false`, and `submits=false`.

## Frozen data conversion

Each of the 16 annotator records becomes a separate COCO image sample even when records share one physical JPEG:

- filename: deterministic `{index:02d}_{image_id}.jpeg` alias to the corresponding allowed source JPEG;
- image size: 2048x2048;
- all source polygons/components preserved;
- category collapsed to one `filament` category with COCO id 1;
- source boxes recomputed from decoded masks and stored as `[x,y,width,height]`;
- source area recomputed from decoded masks;
- no representative-rater collapse, consensus, omitted-label repair, external labels, or image preprocessing.

The same 16-record dataset is used for train and validation because G2 explicitly measures memorization. A syntactically valid identical test split may be materialized for RF-DETR's dataset contract but `run_test=false` and no test dataloader may execute. These are aliases of allowed fit images, not competition test data.

## Model and resolution

Official `RFDETRSegNano` / `RFDETRSegNanoConfig` from `rfdetr==1.10.1`:

- DINOv2-based Nano encoder;
- 100 queries / 100 selected predictions;
- four decoder layers;
- one filament class;
- input resolution **768x768**;
- `mask_downsample_ratio=2`, giving a 384x384 learned mask grid;
- gradient checkpointing enabled;
- official COCO checkpoint above;
- square resize, no scale-jitter crop;
- grayscale source replicated to RGB by the standard loader;
- no custom augmentation (`aug_config={}`).

768 is divisible by Seg-Nano's patch size 12 and is the highest T4-safe regime supported by prior implementation evidence at batch one. A public notebook reported 900px OOM on a 16 GB T4, so V35 does not probe 900/1008/1024 after observation.

## G0 — environment and provenance

Before GPU model execution require:

- exact annotation, selection, wheel, and checkpoint identities above;
- `rfdetr==1.10.1` and recorded runtime versions for Python, Torch, torchvision, transformers, Lightning, torchmetrics, supervision, NumPy, SciPy, and pycocotools;
- package resolves without replacing Kaggle's CUDA-matched Torch/Torchvision stack;
- converted train/valid populations each equal 16 records / 57 annotations / nine physical source names;
- every converted polygon decodes and its recomputed area/box is valid;
- source paths contain no tune/audit/test/public-MAGFiLO token;
- no outbound upload, experiment logger, or Roboflow API use.

Failure closes V35.

## G1 — one-epoch resource smoke

Run exactly one epoch / 16 microbatches on one private Kaggle T4:

- batch size 1;
- gradient accumulation 1;
- BF16/FP16 automatic mixed precision as resolved by RF-DETR;
- gradient checkpointing on;
- EMA off;
- validation only at epoch end;
- finite train loss and at least one completed optimizer step;
- external peak GPU memory < **14,336 MiB**;
- wall time <= **20 minutes**;
- checkpoint save and reload succeed.

Any OOM, nonfinite loss, missing checkpoint, higher peak, or timeout closes V35. Do not lower resolution or mask-grid fidelity after observation.

## Conditional G2 — bounded numerical overfit

Only if G1 passes, launch a new immutable private kernel/version from the same frozen source and identities:

- maximum 2,000 optimizer steps;
- 125 epochs x 16 records, batch/accumulation 1;
- AdamW through RF-DETR's official training module;
- `lr=1e-4`; all other optimizer/scheduler defaults from pinned 1.10.1 recorded at runtime;
- scale jitter disabled; no augmentation;
- EMA off; early stopping off;
- validation/evaluation at epochs 25/50/75/100/125;
- periodic checkpoint every 25 epochs;
- built-in checkpoint selection uses only the same 16 overfit records.

Exact-PQ evaluation uses source-resolution masks returned by the official prediction API. Confidence grid is frozen to `{0.05,0.10,0.20,0.30,0.50}`. For each record, predictions are scored against that annotator record using deterministic one-to-one maximum-IoU matching and strict IoU >0.5. No intensity refinement, morphology, TTA, connected-component splitting, overlap ownership, V17 refiner, or threshold outside this grid.

G2 passes only if all hold at one frozen checkpoint/grid cell:

- aggregate decoded PQ >= **0.85**;
- recall >= **0.90**;
- median matched IoU >= **0.80**;
- finite outputs/losses;
- external peak memory <14,336 MiB;
- completed optimizer steps <=2,000;
- zero forbidden reads/exports/submits.

If G2 fails, close V35. Do not change resolution, mask ratio, model size, query count, confidence grid, epochs, augmentation, loss weights, checkpoint choice, or postprocessing.

## Conditional downstream work

Passing G2 authorizes only a new full-population design document. It does not authorize reading tune/audit/test. Any later experiment must predeclare:

- exact canonical 566-fit / 94-tune / sealed-47-audit populations;
- matched two-seed training;
- full-population resource/time gate;
- canonical V17 control reproduction;
- tune PQ >=0.50 and replication above V17 before audit;
- audit PQ >=0.50 and non-regression versus V17 before one test export.

## Stop rules

Do not:

- use public MAGFiLO labels or solar RF-DETR weights;
- substitute MaskDINO after an RF-DETR failure inside V35;
- lower resolution after OOM;
- use public-notebook intensity refinement;
- tune `mask_downsample_ratio`, queries, thresholds, or loss coefficients;
- inspect canonical tune/audit/test during G0-G2;
- create or upload a submission without separately frozen downstream gates.
