# V33 design — balanced foreground-gated Omnipose FPN

Frozen **2026-09-13 before implementation staging or any V33 model step**.

## Status and separation from V32

V32 remains closed. V33 does not change V32's threshold, losses, architecture, initialization, records, step budget, or decoder after observing its failure. It is a separately named experiment motivated by a new measured diagnosis.

The exact V32 G2 cohort contains 144 native 1024 tiles from 16 fit annotator records. Official-label rasterization shows:

- mean foreground fraction: **0.001435916** (0.1436%);
- median foreground fraction: **0.001064301**;
- 48/144 tiles contain no foreground;
- aggregate background:foreground ratio: **695.42:1**.

V32 averaged distance/flow regression and boundary BCE over complete tiles while initializing distance/background to -5. The overwhelmingly dominant background was already near its optimum. Its DeepLabV3 output stride and all-pixel objectives therefore made empty foreground a predictable optimization attractor, consistent with zero decoded predictions at every checkpoint through step 2,000.

## Hypothesis

A stride-4 feature-pyramid image model can overfit the already validated Omnipose fields if foreground recognition is explicit and sparse supervision is not diluted by background pixels.

This is an optimization/architecture hypothesis, not a claim that tune or public PQ will improve.

## Inherited target/decoder evidence

V33 inherits only V32's passed, contamination-safe G1 evidence:

- pinned Omnipose v1.0.6 commit `21e4d0199cc03662669c150f6151e3365dc201fd`;
- full fit+tune exact-field PQ **0.922493** and recall **0.995220**;
- canonical annotation SHA-256 `5da9e92b5a1a1947fd5d57adb6688269625c48ec1ef884daf2a01618c9ed54a1`;
- fixed suppressed-Euler/sink-clustering decoder and minimum area 20.

V33 adds an explicit foreground logit, which is a normal independent mask channel supplied as `iscell` to the same pinned decoder. Flow/distance generation and reconstruction parameters do not change.

## G2 — bounded numerical overfit

Population and inputs are unchanged from V32 G2:

- selection identity `e561c523b60993e93f82ce03116737ce512f54f4103b4557c29e409c88c92653`;
- first 16 canonical fit annotator records under the frozen grouped split;
- nine official fit images, 57 source instances;
- nine native 1024 tiles per record at starts `{0,512,1024}²`, 144 samples;
- complete-record Omnipose fields cropped after generation;
- no augmentation; deterministic cyclic order; batch one.

### Model

- ImageNet-1K ResNet-50 backbone from the same hash-pinned V1 weights used by V32;
- features at strides 4/8/16/32;
- 128-channel top-down FPN with GroupNorm and SiLU;
- stride-4 prediction head, bilinearly restored to native tile resolution;
- five channels: foreground logit, flow-y, flow-x, smooth distance, boundary logit;
- backbone BatchNorm uses frozen running statistics while affine/backbone gradients remain enabled.

The final head is zero-weight initialized with biases `(-2,0,0,0,-2)`. Step 0 is therefore empty at the frozen foreground-logit threshold 0.0 but positive gradients are not attenuated by a -5 foreground bias.

### Balanced objectives

Ignored overlap pixels contribute to no objective.

- foreground: equal-weight mean BCE over positive and negative pixels plus soft Dice on nonempty tiles;
- flow: foreground-only MSE on the two published `mu*5` channels, normalized by 5;
- distance: foreground-only MSE, normalized by 5;
- boundary: equal-weight mean BCE over positive and negative valid pixels;
- total: `2*foreground + 5*flow + distance + boundary`.

A term with no positive pixels omits the positive mean rather than creating NaN. All 144 tiles remain in the schedule, including the 48 true empty tiles.

### Optimizer, checkpoints, and decode

- AdamW, learning rate `1e-4`, weight decay `1e-4`, AMP, no scheduler;
- maximum 2,000 optimizer steps;
- evaluation at steps 0/250/500/1000/1500/2000;
- blend all nine tile outputs with V32's separable Hann window and edge floor 0.10;
- foreground is `foreground_logit >= 0.0`;
- pass predicted flow/distance and explicit foreground to the unchanged pinned V32 reconstruction;
- report aggregate strict PQ, TP/FP/FN, predicted foreground fraction, and finite channel ranges.

## Gates and stop rules

Full-population training is authorized only if all hold:

- decoded aggregate overfit PQ >= **0.85**;
- all losses and output statistics are finite;
- peak allocated GPU memory < **14,336 MiB**;
- input/population/upstream/backbone hashes match;
- runtime reports no tune/audit/test read and no CSV/export/submission path.

If G2 fails, close V33. Do not rescue it by changing foreground threshold, loss weights, FPN width, initialization, sampling, optimizer, records, steps, or decoder.

If G2 passes, stop and design a separate full-population two-seed training/resource protocol before reading tune. Passing G2 alone authorizes no tune, audit, test, CSV, export, or submission.

## Data firewall

Forbidden in V33 G2: public full-MAGFiLO labels, audit records, test images, solar checkpoints, tune evaluation, CSV creation, export, or Kaggle submission. Only the nine official fit images and canonical training JSON may be read.

## G2 runtime addendum — frozen after version-1 harness error

Private version 1 trained through step 1,000 but produced no complete result: at the step-1,000 checkpoint, finite model outputs triggered a zero-range normalization inside untouched Omnipose v1.0.6, which propagated NaN sink coordinates into DBSCAN and raised `ValueError`. The latest completed checkpoint was step 500: PQ 0.000924, 3 TP / 3,267 FP / 54 FN, predicted foreground fraction 0.031689, peak 1,676.74 MiB. These are interim diagnostics, not a gate result.

Fix1 changes no model, objective, threshold, data, schedule, field, or decoder parameter. It catches only the exact upstream `ValueError` containing `Input X contains NaN`, assigns that annotator record zero predictions, records `decoder_error="upstream_decoder_nan"`, and requires zero decoder errors to authorize success. Any malformed decode therefore makes passing harder and cannot rescue V33. All other exceptions still abort. Fix1 uses a new immutable private slug.

## Final result — closed at G2

Fix1 reproduced the version-1 trajectory exactly through step 500 and continued to a valid step-1,000 checkpoint:

- step 250: PQ 0.0, 0 TP / 975 FP / 57 FN;
- step 500: PQ **0.000924**, 3 / 3,267 / 54;
- step 1,000: PQ **0.041703**, SQ 0.550486, recall 0.087719, 5 / 70 / 52;
- step-1,000 predicted foreground fraction: 0.000413762;
- step-1,000 decoder errors: 3;
- peak allocated memory: 1,677.74 MiB.

At the step-1,500 evaluation, another zero-range Omnipose internal normalization produced NaN sink coordinates and an out-of-bounds `IndexError`. Per the predeclared stop rule, V33 is closed: it is far below the 0.85 overfit gate, already has decoder errors that independently block authorization, and did not complete the bounded schedule. There will be no broader exception handling, third launch, threshold change, loss/architecture adjustment, tune/audit/test read, full training, CSV, export, or submission.
