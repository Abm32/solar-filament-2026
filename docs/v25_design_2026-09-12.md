## Hypothesis

V24 established that multi-rater omissions are real and targetable: replacing incomplete targets with physical-image consensus labels recovered seven additional raw tune instances and 23 end-to-end TP, but directly promoting every disputed cluster to positive increased FP by 61 and lowered PQ. V25 tests the narrower mechanism supported by missing-annotation literature: preserve every original positive unchanged, but reduce incorrect background classification gradients inside regions another rater labeled.

The arm does not add positives, masks, pseudo-labels, or boxes to assignment. Omitted-rater regions are uncertainty metadata only.

## Evidence

- Wu et al., *Soft Sampling for Robust Object Detection* (2019), <https://arxiv.org/abs/1806.06986>: unlabeled objects become incorrect background; uncertain-background gradient weighting improved Open Images by over 3% and recovered much of curated missing-label degradation. Their Gompertz floor is 0.25 and their findings warn that deleting all background is worse than soft weighting.
- Zhang et al., *Solving Missing-Annotation Object Detection with Background Recalibration Loss* (2020), <https://arxiv.org/abs/2002.05274>: one-stage dense detectors are especially vulnerable to missing-label negative gradients. Their best confusing-anchor loss scale was 0.1; zeroing or 0.01 was worse. BRL improved COCO with 50% labels removed by 9 mAP points over focal-loss baseline.
- Pham et al. (2023) and Campi et al. (2026): multi-rater disagreement should be represented explicitly rather than treated as ordinary fully supervised label sampling.
- Project E036/V24: consensus positives increase recall but inflate FP, motivating gradient suppression without positive promotion.

These sources support the mechanism and frozen 0.1 scale, not a competition gain.

## Uncertainty population

Using V24's constrained descending-IoU clustering at strict IoU >0.5:

- train records: 937 across 566 physical files;
- original positive instances: 6,606, unchanged;
- omitted-rater uncertainty boxes: 2,659;
- records containing uncertainty: 541;
- maximum uncertainty boxes in one record: 28;
- transport labels before loss split: 9,265.

For each repeated record, a cluster is uncertain only when none of its member annotation IDs belongs to that record. Its medoid annotation's original COCO bounding box is transported as normalized xywh. The record's own annotations remain the only positive boxes/masks.

## Loss

Both arms use the same custom dataset, trainer, model subclass, and criterion. Sentinel uncertainty boxes receive class `-1` only inside the data pipeline so the same mosaic, scale, translation, and letterbox transforms apply. Immediately before assignment:

1. sentinel rows are separated into `uncertainty_bboxes` and `uncertainty_batch_idx`;
2. they are removed from `cls`, `bboxes`, `batch_idx`, masks, and any instance-aligned fields;
3. stock TaskAlignedAssigner sees only the original positives;
4. stock box, DFL, and segmentation losses remain unchanged;
5. classification BCE remains unchanged except negative anchors whose centers lie inside an uncertainty box receive a scalar weight.

| arm | uncertainty-negative classification weight |
| --- | ---: |
| matched control | 1.0 |
| uncertain-background arm | 0.1 |

Foreground anchors always retain weight 1.0, even if they lie inside uncertainty boxes. All negative anchors outside uncertainty boxes retain 1.0. The denominator remains stock `target_scores_sum`; only selected classification numerators are downweighted. No gradient reversal or pseudo-positive BRL branch is used because V24 measured FP inflation when disputed regions were promoted.
