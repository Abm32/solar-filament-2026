# V32 design — published Omnipose distance/flow reconstruction

Frozen **2026-09-13 before project implementation or full fit+tune oracle**.

## Hypothesis

V31 showed that expert-spine SDT nearly reconstructs the source labels but that
watershed and standard-DT controls are invalid for long varying-width filaments.
V32 tests a separately published representation and decoder: Omnipose smooth
eikonal distance, its gradient flow, divergence-rescaled suppressed Euler
integration, and sink clustering. This is not a V31 threshold or decoder rescue.

Primary claim:

> Exact Omnipose distance/flow fields can reconstruct the canonical competition
> instances with enough fidelity to justify training a native-tile image model.

## Upstream packaging audit

Published v1.0.6 cannot be installed untouched with current packaging because:

1. legacy `setuptools_scm` metadata fails under modern setuptools;
2. `fastremap` is imported but absent from declared dependencies;
3. declared `ncolor>=1.2.1` admits incompatible ncolor 2.x, which removed
   `ncolor.format_labels`;
4. eager top-level import of `peakdetect` uses removed top-level SciPy `ifft`.

A disposable `/tmp` parity environment loads the untouched `omnipose/core.py`
through a minimal package namespace, with `ncolor==1.2.1` and `fastremap`
explicitly present. This environment never becomes a project dependency.

## Frozen reconstruction semantics

The fixed 26-record semantic probe compared only published decoder modes. The
winner was automatic clustering plus adaptive effective-diameter iterations:
mean record PQ 0.895376, 234 TP / 44 FP / 2 FN. Fixed 200 steps and forced DBSCAN
were both worse.

V32 therefore freezes:

- smooth eikonal field generated by upstream `masks_to_flows`;
- flow = upstream gradient of that field;
- foreground = exact source foreground for G1;
- flow preprocessing = upstream `div_rescale`;
- suppressed bilinear Euler integration;
- recurrence: previous/current flow momentum average, then divide by `1+t`;
- iterations: `int(6 * mean(positive smooth distance))`, minimum one;
- `cluster=False` at entry; upstream automatically enables DBSCAN only when
  effective diameter is <=12;
- DBSCAN `eps=sqrt(2)`, `min_samples=5`, with published outlier snapping;
- otherwise rounded sink coordinates and connected components;
- minimum mask area 20;
- exact-oracle flow QC disabled (`flow_threshold=0`);
- no affinity segmentation, forced clustering, HDBSCAN, boundary segmentation,
  TTA, morphology sweep, or threshold grid.

The optional boundary output is a training auxiliary only. Published new-model
v1.0.6 defaults to distance+flow without boundary, and its standard decoder does
not use boundary except for a narrow image-edge defect branch. G1 supplies zero
boundary logits and cannot tune them.

## Data firewall and populations

Allowed only:

- hash-pinned official competition training JSON;
- canonical grouped split: 566 fit / 94 tune / sealed 47 audit;
- generic ImageNet weights only after G1/G2.

Forbidden:

- public full-MAGFiLO annotations, which overlap 139/180 competition test names;
- any audit record during target or model selection;
- any test image before tune and audit authorization;
- opaque solar checkpoints or public prediction payloads.

Frozen G1 population:

- fit: 566 files / 937 records / 6,606 GT;
- tune: 94 files / 150 records / 1,134 GT;
- combined: 1,087 records / 7,740 GT.

Each annotator record is processed independently. Exact pixels occupied by more
than one instance in a record are set to ignore/background in the single-label
flow target; original masks remain the scoring targets. Four fit+tune records
contain such overlap and must be reported separately.

## G0 — upstream and contamination parity

Before the full oracle:

- annotation path and SHA match the canonical competition file;
- upstream commit and every pinned source hash match;
- all frozen populations match exactly;
- synthetic two-instance target reconstructs with PQ 1.0;
- fixed semantic-probe summary matches the committed mode-selection result;
- runtime contains no audit/test/export/submission path.

Failure closes V32.

## G1 — full exact-field oracle

Run untouched upstream field construction and frozen reconstruction on every fit
and tune annotator record, using crop-local computation with a fixed 16-pixel
background margin and full-size RLE scoring.

GPU overfit/training is authorized only if all hold:

- combined global PQ >= **0.90**;
- fit global PQ >= **0.89**;
- tune global PQ >= **0.89**;
- combined strict-IoU recall >= **0.99**;
- false positives / GT <= **0.25**;
- zero-PQ records <= **1%**;
- synthetic upstream parity remains exact;
- all outputs are finite and deterministic.

These values were frozen from the fixed 26-record semantic probe, not after the
full fit+tune result. If G1 fails, do not change iterations, DBSCAN, margins,
minimum area, clustering policy, or fields.

## Conditional G2 — numerical image-model overfit

Only after G1 passes, freeze and implement a native 1024-tile model with:

- DeepLabV3-R50 ImageNet backbone, output stride 8;
- two flow channels, one smooth-distance channel, one auxiliary boundary channel;
- foreground-weighted MSE for distance/flow and BCE for boundary;
- v1.0.6 output scaling: flow target multiplied by 5; distance background -5;
- 16 fixed fit records, maximum 2,000 steps;
- decoded training PQ >=0.85 and finite losses.

No architecture substitution is permitted inside V32.

## Conditional G3/G4 — resource and tune gates

Only after G2:

- full-population one-pass smoke must peak below 14,336 MiB/T4 and project <=4h;
- matched two-seed training, 20k optimizer steps, fixed checkpoints;
- exact frozen decoder, no inference grid beyond distance threshold
  `{-0.5, 0.0, 0.5}` predeclared before training;
- canonical tune must first reproduce V17 control exactly;
- primary V32 tune PQ >=0.50 and replica >V17 to open audit;
- audit PQ >=0.50 and >=V17 audit 0.470763 to authorize one test export.

## Stop rules

Do not:

- use the public full-MAGFiLO labels;
- lower an observed gate;
- force DBSCAN or change its parameters;
- switch adaptive iterations to 200 or tune iteration count;
- enable affinity/HDBSCAN/flow-QC as a rescue;
- tune boundary splitting, crop margin, or minimum area;
- inspect audit/test after any failed gate;
- install Omnipose into the project virtualenv;
- run GPU work before G1 and G2 pass.

## G2 execution addendum — frozen after G1, before implementation

G1 passed on 2026-09-13. The following resolves G2 details left abstract above
and is frozen before staging or any model step:

- selected records: the first 16 canonical fit annotator records ordered by
  sorted fit filename then image ID; identity
  `e561c523b60993e93f82ce03116737ce512f54f4103b4557c29e409c88c92653`;
- samples: all nine native 1024 tiles at starts `{0,512,1024}²` for each record,
  exactly 144 samples; partial instances are retained and overlap pixels ignored;
- smooth distance/flow/boundary targets are generated once on each complete 2048
  annotator record with untouched upstream `masks_to_flows`, then cropped into
  tiles; this preserves one globally consistent field across tile seams;
- each grayscale tile is robustly normalized by its own p1/p99 values, copied to
  three channels, then transformed with ImageNet mean/std;
- deterministic cyclic sample order, no augmentation, batch one;
- model: torchvision DeepLabV3-ResNet50 with ImageNet-1K V1 backbone weights,
  output stride 8, four output channels `(flow_y, flow_x, distance, boundary)`;
- target scaling follows v1.0.6: flow `mu*5`, distance positive smooth field and
  background `-5`, binary upstream boundary;
- pixel weight is `1.0` on foreground and `0.5` on background; ignored overlap
  pixels have weight zero;
- loss is `5*weighted_flow_MSE + weighted_distance_MSE + boundary_BCE`; BCE is
  unweighted and ignored overlap pixels are removed from its mean;
- AdamW `lr=1e-4`, weight decay `1e-4`, AMP enabled, no scheduler, no gradient
  accumulation, maximum 2,000 optimizer steps;
- checkpoints/evaluation at steps `0,250,500,1000,1500,2000`; first checkpoint
  reaching decoded aggregate PQ >=0.85 may stop training early;
- final classifier initialization is frozen to zero weights and biases
  `(0,0,-5,-5)` for `(flow_y,flow_x,distance,boundary)`; this makes step-0
  foreground empty and prevents random untrained logits from launching DBSCAN on
  millions of pixels. The ImageNet backbone remains unchanged;
- evaluation predicts all nine tiles, blends raw four-channel logits into 2048
  using a separable Hann window with edge floor 0.10, decodes at distance threshold
  `0.0` using the exact frozen v1.0.6 reconstruction, and aggregates strict PQ
  across all 16 annotator records;
- hard resource gate: external peak GPU memory <14,336 MiB; OOM or a higher peak
  closes V32;
- this stage may read only the 10 distinct official fit images referenced by the
  16 frozen annotator records. Tune, audit, test, CSV, export, and submission paths
  remain forbidden.
