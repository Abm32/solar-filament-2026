# V45 result — YOLO-family ensemble is complementary but cannot reach V17; hold 0.39

Recorded 2026-09-30 IST. Tested whether unioning several full-population YOLO-seg
models (s + m + l backbones, native 2048) beats a single model and V17 (tune PQ
0.448703) on the held-out 141-file canonical tune split, using cross-model NMS with
agreement voting (keep instance if >=2 models corroborate OR conf >= high_conf).

## Results (held-out tune PQ)
| config | PQ | recall | FP | note |
| --- | ---: | ---: | ---: | --- |
| best single (V44-s) | 0.358 | 0.48 | 320 | |
| plain union (min_agree 1) | 0.352 | 0.555 | 577 | recall up, FP explosion sinks PQ |
| agreement union (>=2 or conf>=0.9), m/l ~35ep | 0.370 | 0.534 | 403 | +0.012 over single |
| agreement union, m/l ~65ep | 0.370 | 0.512 | 337 | ceiling unchanged by member maturity |
| V17 six-source ensemble | 0.4487 | - | - | target |

## Findings
1. Complementarity is REAL: union recall (0.51-0.55) exceeds any single model
   (0.48). The models find partly-different filaments.
2. But the ensemble PQ ceiling is ~0.37, stable whether members are trained 35 or
   65 epochs, and ~0.08 BELOW V17. Same-family models share failure modes, so the
   union adds recall but also correlated false positives that agreement voting only
   partly removes.
3. This independently reconfirms project ledger E028: realistic cross-source NMS
   ensembling barely beats the best single source; the union ORACLE (zero-FP) was
   0.5849 but is not realizable.

## Decision
A YOLO-seg-family ensemble does NOT beat V17. Do not submit; preserve V17
submission 56103401 at public 0.39. A genuine gain would require adding V17's
orthogonal non-YOLO proposal sources (different architectures) to the union, not
more same-family members. Evidence: outputs/v45_ensemble/.
