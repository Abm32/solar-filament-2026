# V38 design — orientation-to-overpass opportunity gate

Frozen **2026-09-14 before V38 implementation or measurement**.

## Decision and separation from closed experiments

V38 is a zero-GPU opportunity audit for the remaining orientation-aware filament
architecture described by Liu et al., *Intersection to Overpass* (CVPRW 2019,
DOI 10.1109/CVPRW.2019.00021). It is not a V31–V37 rescue and does not authorize
model training by itself.

The paper predicts six 30-degree orientation layers, separates close/crossing
filaments before instance assembly, and reconnects direction-changing fragments
through terminus pairing. That mechanism is relevant only if close, parallel,
crossing, or terminus-adjacent filaments account for a material fraction of this
competition's measured proposal-discovery wall.

The project already established:

- V17 tune PQ 0.448702717 with counts `[481.0093129, 704, 306, 430]`;
- six complete detector proposal populations jointly match 922/1,134 tune GT,
  leaving 212 instances missed by every source;
- exact same-record mask overlap is rare: 5/36,064 instance pairs;
- V27 already trained on full images plus frozen V26 native owner tiles and
  regressed, so sliced fine-tuning is closed and is not V38;
- V31–V34 dense field/tube representations and V35–V37 RF-DETR are closed by
  their frozen gates.

V38 asks only whether orientation-associated local geometry is sufficiently
concentrated in the 212 invisible instances to justify a separately frozen image
model. If not, preserve V17 and stop this path.

## Frozen geometry

For each GT instance in each tune annotator record:

1. Densify its expert spine with the existing V31 deterministic polyline rule.
2. For every other instance in the same annotator record, find the globally
   nearest pair of dense spine samples.
3. Estimate each local tangent from samples at radius 3, expanding only when the
   local difference is zero.
4. Compute unoriented angular difference in `[0, 90]` degrees.
5. Mark an orientation interaction when nearest spine distance is <=16 px.
6. Classify an interaction as parallel when angular difference is <30 degrees
   and crossing-like otherwise. The 30-degree boundary is fixed by the paper's
   six orientation branches.
7. Separately mark a terminus opportunity when any endpoint pair is <=16 px.
8. An instance is orientation-addressable when it participates in at least one
   proximity or terminus opportunity.

The 16 px radius is frozen before measurement. It is approximately 1.5 times the
previously measured 11.1 px median effective filament width and bounds the local
interaction zone without using V38 labels to tune a search radius.

No image intensity, morphology, skeletonization, width reconstruction, public
labels, or threshold sweep is allowed.

## G1 — material-opportunity gate

The opportunity gate passes only if all hold:

1. at least 65% of the 212 all-source misses are orientation-addressable;
2. the addressable rate among all-source misses is at least 1.25 times the rate
   among the 922 instances found by at least one source;
3. if every addressable all-source miss were recovered with IoU exactly 0.65 and
   zero added false positives, V17's projected tune PQ is >=0.50;
4. all geometry values and outputs are finite and deterministic;
5. the firewall remains intact.

The IoU 0.65 recovery assumption is frozen from the already measured six-source
union mean matched IoU 0.652178, rounded down. The projected score is an
opportunity ceiling, not a model result. Requiring PQ 0.50 prevents a complex
architecture from being authorized merely to chase another locally tiny delta
that is unlikely to move the public score.

## Conditional G2

Only a passing G1 may authorize a new design for a bounded 16-record numerical
overfit experiment. That later design must be frozen before implementation and
must specify architecture, orientation targets, terminus assembly, generic
pretraining provenance, memory limits, exact PQ/recall/FP gates, and the same
no-audit/no-test firewall. V38 G1 itself never trains a model.

## Stop rules

- Do not change 16 px, 30 degrees, IoU 0.65, coverage 65%, enrichment 1.25, or
  projected PQ 0.50 after observing results.
- Do not substitute a sliced-YOLO experiment; V27 already closed it.
- Do not reopen V31–V37 or blend their outputs.
- Do not inspect audit, infer test, create a CSV, or submit from V38 G1.
- If G1 fails, close orientation-to-overpass for this competition and preserve
  V17 submission `56103401` at public 0.39. The remaining action is validation
  and preservation of the existing best artifact, not another post-hoc rescue.

## Final result — closed at G1

The full frozen tune-only audit completed in 6.1 seconds over 94 physical files /
150 annotator records / 1,134 GT instances. G0 reproduced every signed-cache
regression exactly: per-source matches `841, 794, 826, 884, 843, 893`, union
matches 922, and all-source misses 212.

Only **7/212 (3.3019%)** all-source misses were orientation-addressable: four
parallel, three crossing-like, and four with a terminus opportunity (categories
can overlap). The found-by-any population contained 11/922 (1.1931%), so
addressable geometry was enriched by 2.7676x, but its absolute coverage was far
below the frozen 65% gate. Even perfect zero-FP recovery of all seven at IoU 0.65
would project V17 tune PQ only from 0.448703 to **0.451473**, far below the 0.50
gate.

Therefore `g1_passed=false` and `g2_model_design_authorized=false`. Close the
orientation-to-overpass path without GPU/model work. Audit, test, images, public
Solar data, training, CSV export, and submission remained untouched. Repeated
full execution was byte-identical; result SHA-256 is
