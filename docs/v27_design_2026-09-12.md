## Motivation

V26 established the missing mechanism decisively: native 1024 tiles raised hybrid raw proposal recall from 0.728395 to 0.805996, bottom-area recall from 0.604106 to 0.821114, and rescued 90/228 historical no-proposal instances. Yet final PQ fell from 0.448703 to 0.432869 because a detector trained only on resized full disks produced poorly calibrated/native-tile proposals that did not survive confidence/refinement and added FP.

V27 tests the direct continuation recommended by SAHI: fine-tune the detector on the same native slice domain used at inference while retaining original full images for large objects.

## Primary evidence

Akyon et al., *Slicing Aided Hyper Inference and Fine-tuning for Small Object Detection* (2022), report +5.1-6.8 AP from sliced inference and +12.7-14.5 cumulative AP when sliced fine-tuning is added. Their protocol augments—not replaces—the original training set with overlapping patches, because smaller slices can truncate large objects. V27 follows that principle and keeps V26 geometry fixed.

V26 is stronger task-specific evidence than the paper: raw recall and bottom-area recall moved far beyond their frozen gates, isolating tile-domain calibration/refinement as the current bottleneck.

## Frozen tile population

Use the unchanged V6 physical split: 566 training files / 937 independent annotator records / 6,606 annotations. For every record, create 3×3 native 1024 tiles at starts `{0,512,1024}`.

Each annotation is assigned by bbox centroid to the same nearest-center owner tile used by V26. It becomes a tile positive only if its entire COCO bbox fits in that owner tile. This avoids clipped/truncated positive masks.

Audited population:

- all possible owner tiles: 8,433;
- positive owner tiles: 4,145;
- empty owner tiles: 4,288;
- tile labels retained: 6,593 / 6,606;
- owner-noncontained labels excluded from tile targets: 13;
- labels per positive tile: mean 1.591, median 1, p90 3, maximum 10.

All 13 excluded labels remain available through full-image samples. No annotation is clipped, split, unioned, duplicated across overlapping tiles, or imported externally.

## Matched datasets and update budget

Both control and arm datasets contain exactly **5,622 records per epoch** and run **2 epochs = 11,244 optimizer steps** at batch 1.

### Control

- every one of the 937 original annotator records repeated exactly six times;
- original 2048 image symlinked and resized by Ultralytics to 1024;
- original labels unchanged.

### Sliced-fine-tuning arm

- all 937 original full-image annotator records once;
- all 4,145 positive owner tiles once;
- exactly 540 empty tiles selected deterministically by SHA-256 rank from the 4,288 empty population;
- total = 937 + 4,145 + 540 = 5,622.

The 540 empty tiles give a 9.6% explicit background share while preserving every positive tile. Selection is frozen, label-blind, and identical across seeds. Full images protect large-object/full-branch behavior, matching SAHI's full+slice fine-tuning recommendation.
