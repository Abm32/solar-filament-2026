# V41 design — learned contextual texture/topology overfit gate

Frozen **2026-09-14 before V41 implementation, staging, or model execution**.

## Motivation and separation from closed paths

V39 and V40 jointly identify 91/212 all-detector misses but leave 121 unsupported.
Those 121 occur across 63 tune files, are not limb-edge artifacts, and have the
following official-label geometry: median area 946 px, median spine length 81 px,
median effective width 10.33 px, and 65/121 category 3. Their fixed-ridge median
AUC is only 0.619. Existing proposals and classical filters therefore cannot
supply enough foreground.

V41 is a separately frozen **fit-only numerical overfit gate** for learned
contextual foreground features. It is not a V31/V33/V40 threshold rescue and does
not use their decoders. The architecture synthesizes mechanisms supported by:

- S³-Mamba (Wang et al., 2024): residual fine-detail preservation, channel
  attention, edge/image/intermediate-feature fusion, and multiscale context for
  small low-contrast targets;
- DTU-Net (Lin et al., 2023): decoupled texture and topology networks for weak
  curvilinear responses.

V41 deliberately avoids an external Mamba/CUDA package. A dependency-light
convolutional implementation isolates whether these mechanisms can memorize the
target phenotype on a T4 before any full-population design is considered.

## Fit-only cohort

Use canonical split reconstruction and official competition labels only. For each
fit physical file, choose exactly one annotator record by maximum instance count,
then total annotated area, then stable image ID. Rank records by:

1. descending count of instances with area <=2,000 px and effective width <=16 px;
2. descending count with area <=2,000 px;
3. descending count with effective width <=16 px;
4. descending total instances;
5. filename and image ID.

Freeze the first 16 distinct physical files. Selection SHA-256:

`741d8124fd834c465743cb4ddbee265298354b4e59b5ab9650379d162673ca2c`

The cohort contains 16 records / 16 JPEGs / 308 instances: 260 small, 268 thin,
and 244 both small and thin. Duplicate annotator targets for identical pixels are
forbidden in this bounded memorization test.

Each image produces the fixed native 3x3 1024-tile grid at starts 0/512/1024,
for 144 samples per epoch-equivalent traversal. No random crops, augmentation,
or tune-driven sampling is allowed.

## Data firewall

Allowed:

- hash-pinned canonical competition training annotation JSON;
- exactly the 16 frozen fit records and their 16 official train JPEGs;
- generic framework code shipped in the Kaggle runtime.

Forbidden:

- any other fit record/image;
- all tune/audit/test labels and pixels;
- V17/V39/V40 predictions as model inputs or targets;
- public full-MAGFiLO data, solar checkpoints, or prediction payloads;
- CSV generation, export, and submission.

The result must state `reads_tune=false`, `reads_audit=false`, `reads_test=false`,
`exports=false`, and `submits=false`.

## Input channels

For each 1024 tile, deterministically construct four float channels in [0,1]:

1. raw grayscale robustly scaled at tile p1-p99;
2. CLAHE of channel 1 (`clipLimit=2.0`, grid 8x8);
3. absolute 15x15 Gaussian local-dark residual `max(blur - raw, 0)` rescaled by
   its tile maximum;
4. Sobel gradient magnitude rescaled by its tile maximum.

This is a learned fusion input, not a fixed prediction rule. No channel parameter
is selected from V40 outcomes.

## Targets

For each annotator record:

- foreground: union of all source instance masks, excluding rare overlapping
  pixels from loss;
- spine: radius-2 dilation of each V31-projected expert spine, clipped to its
  source mask and unioned;
- boundary: two-sided one-pixel morphological boundary of every instance;
- instance evaluation targets: original canonical source RLEs.

All expert spines must project validly. Loss-valid background receives weight one;
overlapping source pixels receive zero weight.

## Architecture

`ContextTopologyUNet`, initialized from scratch:

- 4-channel full-resolution stem, stride 1, 24 channels;
- four residual encoder levels at strides 1/2/4/8 with channels 24/48/96/144;
- each residual block uses GroupNorm, SiLU, two 3x3 convolutions, an identity or
  1x1 residual, and squeeze-excitation channel attention;
- bottleneck parallel dilated 3x3 context branches at dilation 1/2/4/8, fused by
  a 1x1 convolution;
- U-Net decoder with bilinear upsampling and high-resolution skips;
- texture head predicts coarse foreground and expert-spine logits;
- topology refiner is a second three-block residual network receiving decoder
  features, sigmoid coarse foreground, sigmoid spine, raw channel, local-dark
  channel, and Sobel channel; it predicts a foreground residual;
- boundary head predicts one boundary logit from decoder features;
- final foreground logit is coarse plus topology residual.

No pretraining or external model download is used in G2. This avoids solar
provenance risk and makes successful exact memorization attributable to the
architecture and losses.

## Loss and optimization

Batch one, native 1024, AMP, AdamW `lr=3e-4`, weight decay `1e-4`, no scheduler,
exactly at most 2,000 optimizer steps, deterministic cyclic tile order.

For final foreground, coarse foreground, spine, and boundary independently use
class-balanced BCE: mean positive and mean negative losses averaged equally.
Add soft Dice to final foreground and spine. Frozen total:

- `2.0 * final_foreground_balanced_bce`
- `1.0 * final_foreground_dice`
- `0.5 * coarse_foreground_balanced_bce`
- `1.0 * spine_balanced_bce`
- `1.0 * spine_dice`
- `0.5 * boundary_balanced_bce`

All terms and gradients must remain finite. No clDice, triplet-loss corruption,
curriculum, threshold rescue, or loss-weight sweep is allowed in V41 G2.

## Evaluation and instance decoding

Evaluate steps `0, 250, 500, 1000, 1500, 2000`. Blend the same nine tiles per
physical image with the frozen Hann window.

Decode final foreground at the predeclared thresholds `{0.35, 0.50, 0.65}`:

1. threshold sigmoid final foreground;
2. remove connected components below 20 px;
3. create seeds from sigmoid spine >= same threshold, clipped to foreground;
4. remove seeds below 5 px;
5. marker-controlled watershed on negative sigmoid foreground within foreground;
6. if a foreground component has no seed, assign one marker at its maximum spine
   probability;
7. remove decoded instances below 20 px.

Select the highest aggregate strict one-to-one IoU>0.5 PQ on the same 16 records;
ties prefer higher threshold and fewer predictions. Report PQ/SQ/recall,
TP/FP/FN, median matched IoU, predicted foreground fraction, and per-record rows.

## Resource contract

One GPU only. Require accelerator name containing `T4`, capability >=7.5, at
least 14,000 MiB total, and no other visible GPU. Fail before image/model work on
unsupported provenance. External `nvidia-smi` peak and Torch allocated peak must
both remain below **14,336 MiB**. Maximum wall time **7,200 seconds**.

No package installation or internet is required. The private Kaggle kernel uses
only the competition source and built-in NumPy/OpenCV/SciPy/scikit-image/
pycocotools/Torch.

## G2 authorization gate

Full-population V41 design is authorized only if one evaluated checkpoint/cell
satisfies all:

1. aggregate PQ >= **0.85**;
2. recall >= **0.90**;
3. median matched IoU >= **0.80**;
4. FP <= **40** over 308 GT;
5. predicted foreground fraction in `(0, 0.02)`;
6. all 2,000 steps complete unless the full gate passes earlier;
7. all losses/outputs finite, checkpoint reload prediction equivalent, external
   and allocated memory below 14,336 MiB, runtime <=7,200 s;
8. exact cohort and firewall identities pass.

These are memorization gates, not tune or public claims.

## Stop rules

- Do not alter cohort, channels, architecture widths/depth, losses, thresholds,
  decoder, optimizer, steps, or gates after observing G2.
- A runtime bug may receive one narrowly scoped fix under a new immutable kernel
  version only if no quality result was produced; scientific settings remain
  unchanged.
- If G2 fails, close this architecture without tune/audit/test access.
- If G2 passes, freeze a separate full-population design before implementation.
  It must use physical-file-grouped OOF/tune evaluation and cannot submit unless
  tune PQ materially exceeds V17 and approaches the corrected >0.6269 local scale
  associated with a plausible public >0.55 result.
